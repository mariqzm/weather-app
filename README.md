# Weather App 
[![Maintainability](https://qlty.sh/gh/mariqzm/projects/weather-app/maintainability.svg)](https://qlty.sh/gh/mariqzm/projects/weather-app)
Веб-приложение для просмотра текущей погоды в любом городе мира.

## Описание

Приложение позволяет получить актуальные данные о погоде по названию города: температуру, ощущаемую температуру, влажность, скорость ветра и атмосферное давление.

## Стек

- **Frontend:** HTML, CSS, JavaScript (Vanilla)
- **API:** OpenWeatherMap API

## Как запустить локально

1. Клонируй репозиторий:
```bash
   git clone https://github.com/mariqzm/weather-app.git
```
2. Открой файл `index.html` в браузере — готово!
